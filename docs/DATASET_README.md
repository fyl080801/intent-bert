# 金融领域BERT三级标签分类数据集

本数据集专为金融用户咨询意图分类设计，适用于BERT模型的微调训练。

## 数据集概述

**总数据量：** 2,300条
- 训练集：2,000条 (financial_intent_dataset.csv)
- 验证集：300条 (financial_intent_validation.csv)

**标签体系：** 三级层级分类
- 一级标签：6个
- 二级标签：24个
- 三级标签：108个

## 文件说明

### 数据文件
1. **financial_intent_dataset.csv** - 训练集（2,000条）
2. **financial_intent_validation.csv** - 验证集（300条）
3. **dataset_labels_info.json** - 完整标签体系说明

### 代码文件
- **src/generateDataset.ts** - 数据集生成脚本

## 标签体系

### 一级分类（6个）
1. **投资理财** - 基金、股票、理财、保险等投资产品咨询
2. **信贷服务** - 贷款、信用卡等信贷产品服务
3. **账户服务** - 账户管理、密码、权限等服务
4. **交易服务** - 转账、支付、缴费等交易操作
5. **产品咨询** - 产品对比、收益计算、费用说明等
6. **风险合规** - 风险评估、合规咨询等

### 二级分类示例
- 投资理财下：基金投资、股票投资、理财产品、保险规划、资产配置
- 信贷服务下：个人贷款、企业贷款、信用卡服务、额度管理
- 账户服务下：开户注销、密码管理、权限设置、安全验证

### 三级分类示例
- 基金投资下：开放式基金、指数基金、债券基金、货币基金、基金定投、基金转换、基金赎回
- 个人贷款下：房贷、消费贷、经营贷、信用贷、抵押贷、贷款计算

完整的标签体系请查看 `dataset_labels_info.json` 文件。

## 数据字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int | 数据唯一标识 |
| text | string | 用户咨询文本 |
| label_level1 | string | 一级标签 |
| label_level2 | string | 二级标签 |
| label_level3 | string | 三级标签 |
| text_length | string | 文本长度分类（短文本/中等文本/长文本） |
| intent_complexity | string | 意图复杂度（简单/中等/复杂） |
| sample_type | string | 样本类型（short/medium/long） |
| keywords | string | 提取的关键词 |
| confidence_score | float | 标注置信度（0-1） |

## 使用建议

### 1. 数据加载
CSV文件已添加UTF-8 BOM，可直接用Excel或Pandas打开：

```python
import pandas as pd

# 读取训练集
train_df = pd.read_csv('financial_intent_dataset.csv')

# 读取验证集
val_df = pd.read_csv('financial_intent_validation.csv')
```

### 2. 模型训练建议
- **输入：** text字段
- **输出：** label_level1/label_level2/label_level3（根据需要选择分类层级）
- **推荐任务：**
  - 单层级分类：只预测一级、二级或三级标签
  - 层级分类：同时预测三个层级的标签

### 3. 评估指标
- 准确率（Accuracy）
- 精确率（Precision）
- 召回率（Recall）
- F1分数（F1-Score）

### 4. 微调建议
- 基础模型：bert-base-chinese 或类似中文BERT模型
- 训练轮数：3-5 epochs
- 批次大小：16-32
- 学习率：2e-5 到 5e-5
